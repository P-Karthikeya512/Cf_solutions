## Problem Statement

<div class="header"><div class="title">B. Medians</div><div class="time-limit"><div class="property-title">time limit per test</div>1 second</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>You are given an array $$$a = [1, 2, \ldots, n]$$$, where $$$n$$$ is <span class="tex-font-style-bf">odd</span>, and an integer $$$k$$$.</p><p>Your task is to choose an <span class="tex-font-style-bf">odd</span> positive integer $$$m$$$ and to split $$$a$$$ into $$$m$$$ subarrays$$$^{\dagger}$$$ $$$b_1, b_2, \ldots, b_m$$$ such that:</p><ul> <li> Each element of the array $$$a$$$ belongs to exactly one subarray. </li><li> For all $$$1 \le i \le m$$$, $$$|b_i|$$$ is <span class="tex-font-style-bf">odd</span>, i.e., the length of each subarray is odd. </li><li> $$$\operatorname{median}([\operatorname{median}(b_1), \operatorname{median}(b_2), \ldots, \operatorname{median}(b_m)]) = k$$$, i.e., the median$$$^{\ddagger}$$$ of the array of medians of all subarrays must equal $$$k$$$. $$$\operatorname{median}(c)$$$ denotes the median of the array $$$c$$$. </li></ul><p>$$$^{\dagger}$$$A subarray of the array $$$a$$$ of length $$$n$$$ is the array $$$[a_l, a_{l + 1}, \ldots, a_r]$$$ for some integers $$$1 \le l \le r \le n$$$.</p><p>$$$^{\ddagger}$$$A median of the array of odd length is the middle element after the array is sorted in non-decreasing order. For example: $$$\operatorname{median}([1,2,5,4,3]) = 3$$$, $$$\operatorname{median}([3,2,1]) = 2$$$, $$$\operatorname{median}([2,1,2,1,2,2,2]) = 2$$$.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test consists of multiple test cases. The first line contains a single integer $$$t$$$ ($$$1 \le t \le 5000$$$) — the number of test cases. The description of the test cases follows.</p><p>The first line of each test case contains two integers $$$n$$$ and $$$k$$$ ($$$1 \le k \le n  \lt  2 \cdot 10^5$$$, $$$n$$$ is <span class="tex-font-style-bf">odd</span>) — the length of array $$$a$$$ and the desired median of the array of medians of all subarrays.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case:</p><ul> <li> If there is no suitable partition, output $$$-1$$$ in a single line. </li><li> Otherwise, in the first line, output an <span class="tex-font-style-bf">odd</span> integer $$$m$$$ ($$$1 \le m \le n$$$), and in the second line, output $$$m$$$ distinct integers $$$p_1, p_2 , p_3 , \ldots, p_m$$$ ($$$1 = p_1  \lt  p_2  \lt  p_3  \lt  \ldots  \lt  p_m \le n$$$) — denoting the left borders of each subarray. </li></ul><p>In detail, for a valid answer $$$[p_1, p_2, \ldots, p_m]$$$:</p><ul> <li> $$$b_1 = \left[ a_{p_1}, a_{p_1 + 1}, \ldots, a_{p_2 - 1} \right]$$$ </li><li> $$$b_2 = \left[ a_{p_2}, a_{p_2 + 1}, \ldots, a_{p_3 - 1} \right]$$$ </li><li> $$$\ldots$$$ </li><li> $$$b_m = \left[ a_{p_m}, a_{p_m + 1}, \ldots, a_n \right]$$$. </li></ul><p>If there are multiple solutions, you can output any of them.</p></div><div class="sample-tests"><div class="section-title">Example</div><div class="sample-test"><div class="input"><div class="title">Input<div title="Copy" data-clipboard-target="#id005442836728963216" id="id00006032845967710032" class="input-output-copier">Copy</div></div><pre id="id005442836728963216"><div class="test-example-line test-example-line-even test-example-line-0">4</div><div class="test-example-line test-example-line-odd test-example-line-1">1 1</div><div class="test-example-line test-example-line-even test-example-line-2">3 2</div><div class="test-example-line test-example-line-odd test-example-line-3">3 3</div><div class="test-example-line test-example-line-even test-example-line-4">15 8</div></pre></div><div class="output"><div class="title">Output<div title="Copy" data-clipboard-target="#id0009256718042510903" id="id007829589226928104" class="input-output-copier">Copy</div></div><pre id="id0009256718042510903">1

It is obvious that $$$\operatorname{median}([\operatorname{median}([1])]) = \operatorname{median}([1]) = 1$$$.</p><p>In the second test case, the given partition has $$$m = 3$$$ and:</p><ul> <li> $$$b_1 = [1]$$$ </li><li> $$$b_2 = [2]$$$ </li><li> $$$b_3 = [3]$$$ </li></ul><p>Therefore, $$$\operatorname{median}([\operatorname{median}([1]), \operatorname{median}([2]), \operatorname{median}([3])]) = \operatorname{median}([1, 2, 3]) = 2$$$.</p><p>In the third test case, there is no valid partition for $$$k = 3$$$.</p><p>In the fourth test case, the given partition has $$$m = 5$$$ and:</p><ul> <li> $$$b_1 = [1, 2, 3]$$$ </li><li> $$$b_2 = [4, 5, 6]$$$ </li><li> $$$b_3 = [7, 8, 9]$$$ </li><li> $$$b_4 = [10, 11, 12]$$$ </li><li> $$$b_5 = [13, 14, 15]$$$ </li></ul><p>Therefore, $$$\operatorname{median}([\operatorname{median}([1, 2, 3]), \operatorname{median}([4, 5, 6]), \operatorname{median}([7, 8, 9]), \operatorname{median}([10, 11, 12]), \operatorname{median}([13, 14, 15])]) = \operatorname{median}([2, 5, 8, 11, 14]) = 8$$$.</p></div>
