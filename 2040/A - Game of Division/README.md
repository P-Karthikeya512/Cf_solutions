The first player wins if $$$|a_i - a_j|$$$ is not divisible by $$$k$$$. Otherwise, the second player wins.</p><p>We play as the first player. Determine whether it is possible to win, and if so, which index $$$i$$$ should be chosen.</p><p>The absolute value of a number $$$x$$$ is denoted by $$$|x|$$$ and is equal to $$$x$$$ if $$$x \ge 0$$$, and $$$-x$$$ otherwise.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases.
